Uma animação por comando

Cada comando do bot virou uma tela sozinha, em loop, para entrar na apresentação sem depender das outras. A copy é a de copy-comandos.md, palavra por palavra.

Para colocar no slide: abra o arquivo e grave a tela, ou embuta com <iframe src="cmd-teto.html?fundo=transparente">. Dá para forçar o tema com ?tema=dark ou ?tema=light, e clicar no aparelho reinicia a animação na hora.
